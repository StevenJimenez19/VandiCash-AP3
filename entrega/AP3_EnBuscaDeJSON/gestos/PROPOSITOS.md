# Propósito de los gestos

1. **Swipe para eliminar:** permite quitar de forma rápida un aviso que el usuario ya no necesita.
2. **Pull-to-refresh:** restaura y actualiza la lista de avisos al deslizar hacia abajo.
3. **Pinch/Zoom:** permite ampliar el comprobante para leer sus datos con mayor claridad.
4. **Long-press:** abre un menú contextual con acciones relacionadas con una cuota.
