# AP3 — Lista de entrega

Equipo: **En busca de JSON**

## Contenido

- `interfaces/`: código HTML y captura de cada una de las cinco pantallas.
- `gestos/`: código relacionado, capturas y propósito de los cuatro gestos.

El archivo de video se añade al ZIP después de grabar las voces o apariciones de los integrantes. Nombre sugerido: `AP3_EnBuscaDeJSON.mp4`.
